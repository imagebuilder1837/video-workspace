# 探索创作

1. 明确目标视频项目，阅读已有文稿、设计、参考和候选音乐。已有结论直接沿用，不重复立项。
2. 访谈方法复用通用 grilling；是否委派遵循实际授权。主动提出推荐、异议、依据和未知，尊重使用者理解取舍后的创作偏好。
3. 共同决定文字、画面与音乐如何分担表达，而非机械分页或照搬原文风格。音乐可以影响结构和视觉，也可反向调整；提供曲目不等于锁定曲目或完整使用。
4. 需要实际看听才能判断时，使用目标项目的局部原型或视频草稿，执行见 [video-produce](../video-produce/SKILL.md)。尽早让整体结构和大致节奏可见，不先精修开头。
5. 达到下述设计范围后，在对话中总结已采纳、仍在试验和未解决的内容，供使用者确认；落盘另由 [video-blueprint](../video-blueprint/SKILL.md) 承担。

## 设计范围

- 目标受众、表达目标与核心内容。
- 宏观结构、大致节奏及文字／画面／音乐的分工。
- 当前音乐与视觉方向、重要限制。
- 已采纳选择的必要理由、未决问题和允许试验的范围。

方向可以是试验，不要求逐镜分镜、字体和精确秒数全部确定。
可在授权内做可撤销的局部尝试；影响内容含义、关键解释、已确认结构或总时长时，返回讨论。“先看看”与沉默不等于认可。

需要新的创作思路时，可按题材参考上游 [story](../../../vendor/hyperframes/skills/hyperframes/references/story.md)、[sound](../../../vendor/hyperframes/skills/hyperframes/references/sound.md)；它们的默认流程和审美建议不替代共同选择。
需要换会话时，由人触发原版 handoff 并传递临时路径、带回自己的判断，不复制视频专用交接机制。
