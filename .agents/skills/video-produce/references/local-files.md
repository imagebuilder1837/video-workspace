# 本地文件

- 项目专属输入归项目；大素材可采用明确的外部引用。
- 通用素材归工作台 `shared/`，按需建目录。保存一份，替换时另存并明确切换。
- 在项目 `assets/` 内建立指向共享目录或文件的符号链接，HTML 用 `assets/...` 引用。先检查现有目标。链接目标相对于链接所在目录计算。
- 子场景仍遵循上游素材路径约定。预览和渲染文件服务允许显式共享链接；编译产物的共享依赖单独核对。
- 字体使用本地文件与 `@font-face`，核对实际加载、字重和中文字形；原因见 [字体依赖](../../../../docs/external/hyperframes-upstream.md#本地制作依赖)。
- 普通 GSAP 时间线复用工作台已安装包 `node_modules/hyperframes/dist/vendor/npm/` 下的 `gsap.min.js`，通过项目 assets 中的链接使用。以安装包实际文件为准；插件只按实际需要加载。
- 结果留存与 Git 边界见 [项目约定](project-layout.md)。
- 项目及共享依赖由使用者手动备份。
