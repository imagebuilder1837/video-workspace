# 本地文件

- 项目专属输入归项目；不宜复制的大素材可明确保留外部引用。
- 通用素材归工作台 `shared/`，按需建目录。保存一份，不覆盖仍被使用的原件；替换时另存并明确切换。
- 在项目 `assets/` 内建立指向共享目录或文件的符号链接，HTML 用 `assets/...` 引用。先检查现有目标，不覆盖用户文件或链接。链接目标相对于链接所在目录计算，不相对于 shell 当前目录。
- 子场景仍遵循上游素材路径约定。预览和渲染文件服务允许显式共享链接，但编译不保证内联目标；两条实际路径都要核对，不能声称视频项目自包含。
- 字体使用本地文件与 `@font-face`，核对实际加载、字重和中文字形；原因见 [字体依赖](../../../../docs/external/hyperframes-upstream.md#本地制作依赖)。
- 普通 GSAP 时间线复用工作台已安装包 `node_modules/hyperframes/dist/vendor/npm/` 下的 `gsap.min.js`，通过项目 assets 中的链接使用。以安装包实际文件为准，不复制一套 runtime 或把 Studio 专用 API 路径当成导出服务器接口；插件只按实际需要加载。
- 保留正在讨论、比较和交付的结果，不覆盖仍在使用的版本；临时排错输出按需清理。大媒体、视频和可重算缓存排除出项目 Git，轻量源码与共享链接可保留。
- 项目及共享依赖由使用者手动备份；Git、符号链接和临时 handoff 都不等于完整备份。
