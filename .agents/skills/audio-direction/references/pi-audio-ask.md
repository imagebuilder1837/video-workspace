# Pi Audio Ask

## 咨询

两个工具均接收 `title`（简短咨询主题）和自由 `question`。问题中携带本轮背景、前次发现与期望回答形式。

| 工具 | 音频组织 |
| --- | --- |
| `audio_ask` | `sources` 一起进入一次远端请求；Responses 可用 `continueFrom` 针对已有听音上下文续问 |
| `audio_ask_batch` | `items` 的每项包含一组 `sources`，整组保持在同一请求中，工具按限额组批 |

来源用 `path` 指定，`start`／`end` 是可选源秒区间，`label` 提供可读说明。省略区间时听完整音频。结果保留素材组、来源与各批回答的关联。

素材变换记录在 `submitted` 中；MP3 裁切可能向外覆盖切点。片段零秒对应 `submitted.start` 源秒。时间引用使用来源标识与源秒。

多批结果由主代理结合当前问题理解、整理，少量相关材料可以再作共同咨询。发生部分失败时，已完成回答与剩余素材范围保留在记录中。

## 听音续问

准备围绕同一组材料继续追问时，首轮设置 `allowContinuation: true`，允许 Responses 为续问保存本轮。普通咨询以 `store: false` 执行。后续使用该轮的 `record.json` 路径作为 `continueFrom`，提供新 `title` 与 `question`；音频上下文来自前序响应。续问默认保留继续追问的能力，设 `allowContinuation: false` 可结束当前分支。其他可用轮次仍可分别续问。

使用原端点与模型。百炼文档给出的响应 ID 有效期为 7 天；响应失效或改听新素材时，按当前问题选择相关选段开启新咨询。

## 档案结构

路径相对工作台根：

```text
.media/audio-ask/
  index.md
  records/<时间与唯一标识>--<咨询主题>/
    record.json
    report.md
  assets/<音频内容指纹>/
    index.md
```

- `record.json`：原始问题、输入、实际选段、批次回答、模型、用量与请求尝试的来源记录。
- `report.md`：同份记录的可读视图，完整保留自由文本回答。
- 根索引：咨询主题、日期、状态、文件名及记录链接。
- 音频索引：内容指纹、已知文件路径、涉及该音频的咨询主题、覆盖选段和链接。

同一音频文件的改名或复制关联到同一索引。重新编码或修改后的文件以新指纹登记。多音频咨询保存一份，各素材索引链接到同份记录。续问报告链接上一轮，并标明继承的音频范围。

历史观察可供跨项目参考；当时的创作适配判断连同原问题理解。每次调用都开展新的远端咨询。
