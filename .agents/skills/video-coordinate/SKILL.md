# 复杂项目协调

借用通用 implement-spec 的任务图、新上下文与集成机制；制作使用视频能力，不套 TDD、固定工种、强制执行者自检或末尾代码审查。主代理负责调度、集成与共享资料，不承担成果复核。

## 前提

1. 明确目标项目、本次授权范围，读取当前设计、相关票及讨论、本地指引。必须已提供 tracker 和项目自己的 Git；缺配置提示先运行 video-setup，不在此入口退化为无 tracker／无 Git 的执行流程。
2. 核对 Git 根目录确为目标项目，已有可用提交且工作区干净；否则说明并暂停，按明确授权处理基线或未提交修改，不自动全部提交、stash、重置或覆盖。Git 外素材与视频仍按 [项目约定](../video-produce/references/project-layout.md) 留存。
3. 首次调用子代理前读取实际配置与能力，按任务选择执行者，不固定 agent 名称或自建调度接口。缺少所需隔离／执行能力或启动失败时报告阻塞，不擅自换运行方式。

## 派发与集成

1. 从当前制作基线建立集成分支，按任务依赖派发已就绪的工作；本地票遵循 [tracker 约定](../video-tasks/references/issue-tracker.md)。需要额外拆分时先用 video-tasks 确认粒度，不自行扩展本次范围。
2. 每个执行子代理使用新上下文，尽可能后台运行。修改版本化制作文件的任务默认使用基于集成分支的独立分支／worktree；只读调查、分析或 review 不为形式另建 worktree。并行写入者须隔离，不能安全隔离时报告阻塞。
3. Brief 提供工作台与实际执行目录、当前设计／任务、必要素材及能力的可解析指针，并说明相关意图、已确认视听约束、可改范围、预期产物和验收要求。共享设计和任务票由主代理维护；执行者通常只改本票制作文件，需改变设计时回报。制作复用 [video-produce](../video-produce/SKILL.md)，问题驱动原型复用 [video-prototype](../video-prototype/SKILL.md)，不重作全局创作选择或读取全部聊天。
4. Git 不携带媒体与生成物；执行目录先核对原项目 Git 外输入和共享链接的可达性，按 [本地文件](../video-produce/references/local-files.md) 取用，不复制整份项目。执行者仅提交本票版本化改动，返回分支／提交、实际产物、所做检查与未知、阻塞及交付／handoff 路径；临时执行路径不成为正式作品依赖。
5. 主代理优先用确定性命令合并，仅在语义冲突时调用合并子代理；不逐票增设成果复核。集成成功后更新状态并派发新就绪任务，需要实际判断／检查结论的依赖仍须取得该交付。与集成分支的机械同步在任务分支处理，保留用户及其他任务改动。

## 统一审查与修正

1. 本次范围的任务集成后，派一个独立新上下文子代理使用 [video-review](../video-review/SKILL.md)，对照当前设计、任务验收条件和实际集成结果统一核查。提供正确的源码状态及实际预览／导出，必要取证可由该子代理完成；分支上的旧产物不能替代集成结果。
2. 只审查一轮。发现授权范围内的问题时，交给一个新的执行子代理集中修正、提交，再由主代理集成；小修正沿用受影响原票，不每项 finding 新开票。需要改变关键创作选择的问题先转 video-discuss，不能当作普通缺陷代作决定。
3. 修复集成后交给人查看，不自动再派 review 或由主代理补审。票与交付说明区分已审对象、修复者报告的处理、修复后未复审和待人工判断事项；不沿用旧证据声称修改后已通过检查。`done` 表示本轮处理结束，不等于作品获认可；依赖人的判断作为交付的任务仍须等到实际判断。

## 设计变化

采纳改变设计的反馈后，主代理在唯一设计正文同步实际受影响内容，更新相关票与依赖，通知、调整或停止受影响的执行者；未受影响工作继续保留。取消票保留原因，晚到的旧设计结果不自动合入。共享设计的写入责任见 [项目约定](../video-produce/references/project-layout.md)。

## 交付与清理

1. 返回集成分支／提交、实际产物及范围、一轮审查发现、修复情况、未检查与待人工判断内容；不从本次协调推导最终成片授权。
2. 保存子代理交付／handoff 路径。清理前将必要 Git 外产物与证据留在正式项目适用位置，明确实际文件，不只留下指向待删除 worktree 的路径，也不建产物台账。
3. 使用 `worktree.discard` 清理本轮创建的执行 worktree，不扩大到用户已有工作区或原型分支。失败或中断先报告并保留恢复所需内容，不强行销毁未交付工作。

人工跨会话接续仍由人调用原版 handoff 并传递临时路径；保存子代理交付上下文不触发该 skill，也不新增固定项目交接文件。
